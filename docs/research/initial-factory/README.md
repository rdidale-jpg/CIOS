## Run and reproduce

```sh
python tools/research/initial_factory.py docs/research/initial-factory/register-replay.json NEW_OUTPUT_DIR
```

The default mode replays the recorded register fields in one bounded wave. No scheduler or durable state process is launched. For a separately commissioned public register read, supply a single commission object and `--acquire-register`. It fetches one exact official company page and up to four specified PSC pages, using HTTPS with redirects disabled, a response limit and timeouts. The command reports gaps for inaccessible or invalid sources and pursues eligible independent inputs. No copies of full pages are bundled. Replay anchors are minimally retained factual observations in synthetic HTML wrappers, with the captured original hashes kept separately from replay hashes. They are not original archived documents.

### Architecture and commercial critique

This lane makes a real first pass from original register research to isolated factual workspace changes. It proves the same identity, Evidence and Observation machinery across four industries. The durable proof uses the actual Blueprint services with explicit fixture authority. A transport checksum verifies bytes, not the truth of promotional material. Register entries attest what the register lists, not ultimate commercial control or actual operating activity. This is a narrow slice of factory v1.0. The package still requires a governed production binding and review. It leaves broader financial, operational and analytical acquisition, controlled current-state invalidation after real source withdrawal, and wider executive view updates to later authorised work.

Continuous monitoring remains deferred until baseline sufficiency, useful analysis, owner-accepted executive presentation and a separate operating policy exist. The current lifecycle checks and unrelated monitoring paths are preserved.
