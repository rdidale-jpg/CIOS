# Evaluation boundary

Before running the sprint proof, require exact safe outcomes for the controlled cases. A publisher can verify its own dated notice only. A related page, duplicate, expired or withdrawn revision, a publication-date mismatch and a material contradiction must never yield verification for the target notice. Multiple pages by the same publisher do not establish independent confirmation. Repeated runs over identical inputs must give an identical decision.

The live test must start with index addresses and question terms, with no target article chosen in advance. Record target coverage, attempts, newly located evidence and decisions improved. The Azure notice is a pre-existing reference from #718 and #720, so the retrieval test does not estimate field accuracy. A representative independently labelled newsroom corpus remains required for extraction, entity/event resolution, corroboration and conflict rates. No statistical interval applies to the purposive cases.
