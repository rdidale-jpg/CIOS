## Architecture and self-critique

Reuse is deliberate: the existing Gold renderer, original illustrations, Top/Left/Main, contextual streams, presentation semantics and existing Source-owned assessment. No new knowledge store, registry, background service, global toggle or qualification engine. Generic disclosure checks only narrow presentation for sources carrying the new exact bindings. They do not admit an issuer or source. The candidate Understanding review is rebound to the additive assessment without changing original source judgments or relationship assessments; it remains candidate intelligence, not owner Evidence acceptance.

A real integration defect was corrected: older FCA/EAI composition set the assessment clock back to its November release date. A newer November 18 announcement then invalidated the combined model and suppressed the older service detail. Composition now retains the later assessment date while preserving every original source's publication/measurement period and release cutoff.

Visual critique: leadership is a membership composition rather than an unproven organogram; workforce uses population columns; technology uses an operating story; programmes use dated threads; goals use distinct horizons and executive choices. The first screen remains longer than a single viewport and thirteen leaders require scrolling on tablets. Financial depth is constrained by actual eligibility, not solved by decorative charts. Real Chromium previews are emulated devices, not physical Safari/iPad certification. No independent-agent critique was commissioned for this sprint; this is a factual, architectural and commercial self-review.
