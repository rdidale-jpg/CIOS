# RUD-1 — routine factual research in FLORA

Research by default. Intelligence by design. Governance by exception.

This is a working implementation, not a five-bank earnings rollout. It adds real Nationwide financial intelligence and exposes source-backed legal-bank service intelligence for all five banking exemplars (six entities including TSB). Four issuer earnings sources still have genuine source-use or capture exceptions. No candidate is promoted to Evidence, Observation, Enterprise Model, Material Pressure or Pipeline.

## Removed barriers and retained boundaries

The Financial selection adapter is data-driven rather than BoE-only. New working research has no whole-release admission hash, individual human claim/document approval, canonical Evidence ID or universal30-day approval-expiry prerequisite. Source-level factual-use rules, located factual bindings and current lifecycle checks determine eligibility. Historical BoE payload, ID, source cut and original adapter remain compatible.

One authorised **Refresh published research** action prepares all eligible working runs through existing Financial persistence. It is not an approval screen. GET never creates data; repeated refresh is idempotent. Missing/invalid sources are filtered before nested journal writes. An unexpected write-time race fails the existing transaction atomically rather than swallowing a poisoned journal.

The method does not confer a blanket licence to public reports. Actual restrictions, third-party content, unsafe origins, private/revoked/contradictory records and unresolved uses remain exceptions. SEC/ONS remain blocked; ADR-027 remains Proposed. There is no general scraper, autonomous/paid research or export service.

## Owner walkthrough

1. In an authorised non-production FLORA workspace with existing Banking resource ACL and `package.upload`, open `/industries/banking`.
2. Select the contextual bank profiles; confirm each exact legal entity, reporting period, counts and optional sources. Switch Landscape/Forces and use Back/Forward.
3. Choose **Refresh published research** once. The existing secure POST preserves session, workspace, Origin, CSRF and audit boundaries; no rights or source parameters are accepted.
4. Open **Nationwide · earnings and integration economics**. Review underlying and statutory profit, signed amounts, member rewards, financial definitions and exact period. Inspect source/method only when wanted.
5. Open the existing analysis-detail link; both pages use the same generic analytical composition.
6. Verify the isolated withdrawal proof: Nationwide output disappears, immutable run history is retained, and independent BoE/FCA material remains usable.

No new canonical Enterprise identities were invented. Non-Lloyds bank views are contextual Industry subjects, not full canonical Enterprise Twins or authority to private enterprise records. Working monetary data remains workspace/resource-bound; public service facts contain no private tenant records.
