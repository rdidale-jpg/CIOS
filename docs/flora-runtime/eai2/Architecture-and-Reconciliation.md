## Owning contracts

CIOS-AI, the Reference Architecture/Design Doctrine, Chief Architect Handbook and accepted ADR-002/005/009/010/012/014/015/016/024/026 govern this bounded implementation. Reports remain views; Evidence, Observation and Enterprise Model ownership remain unchanged. No recommendation, pressure qualification or Opportunity is derived from the added metrics.

`visual_streams.Context/resolve/url` still owns routing, subject identity, selection and stream navigation. `visual_panels` composes the already-resolved `leadership_agenda.Issue` and existing `intelligence_presentation.Statement`; it neither imports evidence nor creates facts. The agenda remains the existing read-only Option A owner. The source registry, official publisher validator, Banking/Macro contracts, authorised owner services, matcher, Offers, seller development and Pipeline remain unchanged.

The optional basis renderer is shared by Main and agenda. There is one source/semantic decision path, not a new Main intelligence model. The private/revoked candidate check runs before a title, preview or link is returned. A denied optional complaint expansion falls back to the original permitted received-only statement under the same key. If the received-count source itself is denied, the compound row is withheld. No closed-minus-received backlog metric is calculated.

The deposit calculation reuses exact source-bound Group facts and their unit, period, actual/reported state, entity and basis. If either input is ineligible, the delta disappears while independently eligible existing financials remain. No second chart is created. UK Forces retains its original neutral statement: it does not restate the new percentages as Reported. The estimated survey view remains available through the same agenda across both streams.
