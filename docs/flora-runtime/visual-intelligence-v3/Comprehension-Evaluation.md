# V3 commercial journey evaluation

**Unmeasured; zero human participants.** Browser automation is functional evidence, not evidence of improved sales outcomes, comprehension or qualification quality.

Use matched v2 and v3 conditions with the same Banking/Lloyds source snapshot. Give the v2 group the existing commercial dossier and Pipeline links as well, so the comparison tests navigation/presentation rather than withholding information. Include the retained platform/estate counterevidence, missing buyer/budget and identical qualification criteria in both conditions. Record code versions, source digests, viewport and participant experience.

Recruit 6–10 owner/sales/research users and counterbalance condition order with equivalent but different questions. Use only public research and disposable synthetic Pipeline records. No production accounts or customer information. Ask users to:

1. Find a Core Platforms hypothesis and explain why a strategic priority does not prove buying intent.
2. Identify supporting context and the conflicting platform/estate statements, preserving scope/date.
3. Name the missing buying, funding, procurement and incumbent information; distinguish inferred roles from verified authority.
4. Explain each attractiveness/access/evidence dimension without treating it as win probability.
5. Deliberately capture/link, explain the Discovered state, provide synthetic qualification references and confirm a permitted stage change.
6. Reopen the same hypothesis, demonstrate duplicate linking and return to the originating industry activity.

Record accuracy against a source-scoped answer key, time, navigation/backtracks, success finding counterevidence, mistaken commercial-certainty claims, duplicate creation, perceived clarity (1–5) and confidence. Observe keyboard and landscape-tablet use. Report paired results, device/role mix, ordering, exclusions and incomplete tasks. Faster navigation with worse evidence classification is not improvement. No percent improvement or production sales-value claim until actual participants complete the protocol.

Current results: time, accuracy, clarity, sales effectiveness and qualification quality **unmeasured**.
