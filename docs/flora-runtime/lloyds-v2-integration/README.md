- **Newly usable.** The opening explains how three H1 business profits become H1 statutory Group profit, then shows the separate Q3 Group contribution. The complete nine-month movement is visible. On each business landing there is now a source-backed link from the operating and financial context to the reporting business's workforce and a specific reported result. - **Connected evidence.** A single finite association resolves through current owner projections on each request. Sources, scopes and periods can be inspected. Strategy connects actuals, milestones, separately dated targets, renewal, funding, service and capital choices. No new independent evidence, canonical records or research facts were admitted by this implementation.
- **What remains missing.** Original purpose and strategic commitments with comparable long-term actuals, workforce and process economics, matched peer metrics across all markets, detailed infrastructure and estate and the authorised production workspace binding. See the [search and integration backlog](#remaining-research-backlog).
- **Reusable.** The financial compatibility helpers apply to typed public financial rows without an issuer name or required currency. Equinix provides a separate test. Evidence-path selection works over existing eligible reported facts without storage, while the route/domain definitions here remain Lloyds-specific. The code does not claim another enterprise has been integrated.
- **Next.** Use the verified financial opening and existing chronology as anchors. Authorise a focused recovery/acquisition sprint for the missing original strategy vintages and a decision-grade process, resource and peer slice in each business. Complete the binding check before any durable enterprise association could be considered.
