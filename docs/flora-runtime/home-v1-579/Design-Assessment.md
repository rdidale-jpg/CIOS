# Design assessment — Hybrid Home v1

## Direction

A panoramic commercial world provides the memorable front door; a compact seller perspective and editorial briefing provide utility. The illustration uses a warm ivory/forest-green palette, botanical edges and a continuous river/city composition instead of framed industry cards. Banking is a classical financial centre with a Canary Wharf/London skyline cue; Technology is a glass campus; Aviation is an unbranded terminal/runway. These are conceptual visual regions, not claims about actual facility locations, supplier relationships or national economic coverage.

The country cue is a small, explicit selector, with a labelled globe window to Global forces. PESTLE is a separate compact overview reached in one step; six panels do not crowd the illustration. In the business briefing, original source dates, a meaningful consequence and one useful action take precedence over administration and evidence status. Sources and uncertainties remain available on request.

Public and signed-in views use the same composition. A public viewer never receives sample private focus or generated plays. The signed-in example uses real authenticated fixture paths and a clearly illustrative company. Real Home recommendations reuse employer-approved/current Offers and existing account-permitted assessments with source segments, retaining validation posture and stable IDs. Priority-account text is the seller's private declaration, not evidence of a relationship or of presence in the selected country.

## Visual refinements during the sprint

- Shortened the hero to one headline so the briefing sits closer to the world rather than after a second large headline.
- Feathered all artwork edges into the page and put focus text on quiet paper. No visible image frame, dashboard panel grid or extra infographic legend.
- Kept the three initial region names visible; on narrow screens the same anchors form a readable native strip instead of overlapping small hotspots.
- Removed large inherited source-detail boxes from this new presentation. Disclosures are quiet text, with 44px activation targets, below the insight action.
- Used a local minimal account menu with the existing workspace/sign-out handlers. Public preview shows Sign in, not inactive workspace/sign-out controls. This does not change the current Home or global authentication owner.
- Normalised arrow glyphs for reliable font rendering and added a real focusable skip destination.
- Grouped existing plays across accounts before repeating one account; no matching dimensions or scores changed.

## What the previews establish

Desktop shows a readable panorama, three discrete labels, compact focus and two-column briefing. iPad landscape retains this composition; portrait gives the reading column more room and stacks the briefing when needed. Mobile preserves body reading and native navigation at 390px; an additional 320px check verifies overflow/touch targets. Reduced-motion mode requires no alternative animation path because no motion is necessary. Print prioritises the text and accessible region links.

Country switch is a design-system test: France changes the artwork and explicit selected market while withholding unsupported local briefing/industry/account content. Its English UI and limited existing macro links are intentional prototype boundaries, not a claim of a complete French market product. Economic PESTLE currently has no qualifying selected signal; the design handles this gracefully rather than synthesising macro statistics.

## Tradeoffs and manual review

The immersive world deliberately occupies much of the first iPad landscape viewport; the briefing follows immediately. The owner should assess this balance on a physical device. Labels are useful navigation, not a precise cartographic overlay; artwork replacement requires reviewing the declared image-relative positions. The original generated artwork is encoded as local WebP (roughly 0.5 MB per country) and only the selected country's asset is requested; no external font, iframe or map service is needed. Actual production LCP, Safari masks, zoom/reflow and assistive-technology experience remain unmeasured.

What's Changing is a bounded editorial projection of existing records, not a live news ingestion service. Some consequential source dates are older; they are displayed honestly and never labelled recent from a retrieval timestamp. Source refresh, broader global Economic/Social coverage, actual French industry intelligence, localised French copy/currency/date preferences and a durable user-selected-market preference require later approved work.

Before approval, inspect public/seller desktop and both iPad sizes, the French empty state, Global PESTLE, a native play link and mobile text. After approval, a separate implementation decision can replace canonical Home and connect a deliberately owned active-market preference. This sprint does not assume that acceptance or change the release branch.
