## Implementation plan

1. Versioned UK-technology coverage specification and source-policy/operation-rights contracts. Discover bounded source-owned cohorts, record selection/exclusion rules, UK relevance, overlaps and gaps; no exhaustive/key-company ranking claim without evidence.
2. SQLite **operational** ledger for programmes/jobs, checkpoints, idempotency, receipts, role-specific acquisition/verification records, releases and dependency invalidation. Explicit caller-selected isolated root; no production store or public access to live jobs.
3. Working establish state machine with finite source requests, per-job request/byte/retry/cost caps, cancellation and resume. Enrich/monitor/reconcile are explicit extension points, not enabled unattended modes.
4. Independent acquisition/checker stage reads supporting evidence again rather than reusing the researcher's file. Deterministic identity, dates, locator, rights, provenance and literal extraction gates can release only the narrow claim classes they substantiate. Model semantic assurance is a distinct extension; unresolved inference is withheld, not sent to Rob for routine approval.
5. Release controller composes versioned research projections from canonical candidate/evidence objects. It cannot promote canonical records or qualify Pipeline. Correction events invalidate dependent edges/hypotheses/indexes/visuals and rebuild current projections while preserving earlier releases.
6. Demonstrate actual permitted official-source retrieval and a selected provider's bounded baseline; mark tooling/acquisition limitations precisely. Private/sensitive/unlicensed content cannot enter shared output. Fixtures and live research remain separate.
7. Add a finite read-only programme view through the existing FLORA visual shell, evidence/gap inspector and industry catalogue. Public pages read only pinned repository release assets, never operational/private stores.
8. Test the trust/rights/identity/lifecycle boundaries, compare strict local and hosted results to actual main, capture real desktop/tablet/phone screenshots and publish a new draft PR. No merge, deployment, paid commitments or unattended monitoring.

Role separation is executable responsibility separation, not a claim of independent human review or a guarantee of truth. Fresh acquisitions from one publisher remain one source family. The same orchestration environment does not establish model independence; literal/schema checks and any future semantic assessments are reported separately.
