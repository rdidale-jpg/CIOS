## Evidence-quality rules

The view distinguishes original primary documents (original bytes verified), retained primary excerpts, index-only excerpts, independent-publisher secondary reporting, unverified references and interpretations/unsupported assertions. A locally checked quote proves that the statement was retained, not that its real-world implication is true.

Exact-support review is bound to statement digest, entity and reporting period. Additional corroborating/contextual sources attach to the same candidate Observation identity with an explicit provenance-link reason; they do not overwrite canonical source lists or create duplicate accepted Observations. Excerpts need an exact retained quote and matching locator. Unsupported scope, altered bytes, future material and wrong-entity evidence cannot establish direct support. Old publication dates and unknown publication dates remain visible even when retrieval is recent. Original-byte hashes remain null when only an approved-tool excerpt is available.

Publisher groups are derived from known source hosts rather than arbitrary display names. Duplicate document URLs, copied excerpt hashes, same upstream assertions, missing independence rationale, unreviewed ownership and ineligible sources cannot manufacture independent corroboration. Separate publication of management guidance is useful context, not an independent measurement of achieved benefits. The semantic independence judgment remains an inspectable candidate review, not automatic truth certification.

Factual relationship classification requires an explicit reviewed triple and exact supported claims at the recorded scope/period. Context can support an analytical mapping but cannot prove its causal effect. Missing endpoints remain unresolved. Counterevidence and a real same-scope successor are required for contradicted/superseded classifications; cycles and silent scope changes fail. The seven-stage visual is explicitly an enquiry map, not a manufactured causal chain.

## Validation and limitations

The new mandatory CI suite covers reproducibility, all source classes, fabricated corroboration, exact entity/period/locator binding, causal restraint, future/index-only material, supported counterevidence, supersession/history, canonical ID retention, v2 wave replay and exports, exact public routes and both enterprise journeys. The local full gate passed with **1,052 passed, 57 matched inherited failures and ten original skips**; all 388 security tests pass. Focused final understanding tests: **36 passed**. Separate CI-policy tests: **25 passed**; actionlint passes. Final refinements are checked with the focused tests and browser journeys; actual candidate-hosted results remain required. Existing inherited-failure identities/signatures and original skip reasons are unchanged; the comparator is unchanged. Actual local and hosted test results are reported on the draft PR and in the completion response, not inferred from previous CI.

This is not complete IT-001 intelligence density or RG-002 autonomous Workspace conformance. No independent human validation has occurred. Semantic support and source-independence judgments need continued challenge; much of the graph remains interpretive. There is no demonstrated causal AI benefit, current supplier contract detail, customer-verified budget, buyer or buying intent. An original-byte archive is possible only through the permitted verified-download route, not by hashing tool-rendered text and calling it the original PDF/HTML.
