# Lloyds financial intelligence

Open Lloyds in Flora, then select **Reported earnings** for the income and profit bridge. **What each business contributed** opens the H1 business comparison. The existing funding and capital selections carry lending, deposits, hedge contribution, liquidity and risk capacity. Select a chart to inspect the reporting scope, period and source locators. Commercial Banking retains its operating and leadership paths. Forces → Efficiency objective shows the FY guidance in context.

## Source and authority

The signed bridge reproduces the economic logic in LEI-1 and Wave 3 using newly verified numeric bindings from the **original EDGAR filing copies**. The existing public-statements service provides read-only typed facts, comparisons and withdrawal. Equinix demonstrates portability of the chart contract with its existing USD inputs. No private run or canonical write is used.

- **Integrity:** verify EDGAR CIK 1160106, accession, publisher, report version, precise definition, dates, accounting basis, units, original signs, and matching exact source lineage. Published comparative columns are used as presented in their respective reports. No mixing of gross and net loans, accounting and prudential capital, half-year and year-to-date flows, or consolidated and legal-bank scope.
- **Security:** private Financial-run ACLs and Source/canonical authorities stay in effect.
- **Specific restriction:** the Lloyds investor-site operation remains held and §5 direct PDF links remain deferred. The old PFI snapshot remains inactive. The EDGAR originals are public regulatory filings independently obtained through the existing SEC publisher/accession validator. No copy of the issuer site or substitute for a blocked private acquisition is retained.
- **Removed blanket rule:** the published company name is no longer an eligibility veto at the financial projection. Existing Source policy still decides each operation. The F1 private-run decision continues to apply to those runs. It never conferred an issuer-wide prohibition for independently eligible regulator filings.
- **Out of scope:** no protected table layout or prose reuse, no new per-report or per-measure approval, no stored Financial runs, no buyer mandate or spending inference, no financial allocation to teams, programmes or supplier contracts.

The four accession bindings and document digests are in the existing Source catalogue. Use the [SEC submissions index](https://data.sec.gov/submissions/CIK0001160106.json) to retrieve the original HTML under SEC access conditions. With the originals in a temporary directory and `lxml` installed, run `python docs/flora-runtime/lloyds-financials/retain.py ORIGINALS DESTINATION --inspected RECORDED_TIMESTAMP` against a copy of the Source package directory. The script writes only minimal numeric facts and provenance. The report owner must explicitly review corrections and differing comparatives. Bounded eligibility, withdrawal and conflict tests remain in the existing statement suite.

## Browser reproduction

From the repository root, run `python docs/flora-runtime/lloyds-financials/browser.py OUTPUT` with Playwright and Chromium installed. The script uses an isolated data directory and runs desktop and both simulated iPad orientations. It exercises actual chart selections, evidence, Back/reload, and Banking and Aviation compatibility.
