## Corrections from independent review

- Expired provider bans no longer deny forever; malformed binding/envelope shapes
  produce finite denial and transplanted session/subject/issuer envelopes fail.
- Public render caches only a provider denial for that one render, never positive
  authority across requests; next request retries current provider verification.
- Old active approval cannot reactivate a deactivated binding; a CIOS principal
  cannot be silently shared by multiple active provider individuals.
- Setup explicitly forbids replacement authority creation, email/first-user role
  inference and automatic legacy fallback. External revocation claims are bounded
  honestly by actual getUser behaviour and token expiry, pending live proof.
- Financial paper corrected adjustment labels to retained income-basis and
  acquisition-expense definitions; no invented fair-value explanation.
- Local-mode rollback now explicitly requires reviewed revocation of still-valid
  historical local sessions; changing configuration is not global revocation.
- ADR-024's Draft header / Accepted body inconsistency is reported, not rewritten
  or used to loosen its existing accepted ownership constraints.
- Auth uses FLORA ivory/forest styling, ordinary unavailable copy and explicit
  workspace label. Public facts do not require private-run preparation.
- Owner/private Financial composition now retains the same separately scoped
  Society complaints section as the public composition; authentication must not
  hide relevant permitted public facts. A content assertion and browser assertion
  cover both financial and Society service intelligence.

Non-blocking observation: workspace Select and Sign out have similar visual
weight. No further visual redesign is necessary for this bounded repair.

missing Render security storage and production latency remain unverified. Provider
