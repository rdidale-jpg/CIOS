## What changes

Banking Landscape now leads with the role of deposits, lending and payments, dated Bank Rate and the broader Finance & Insurance share of UK GVA. Two short strategic themes lead into an inline enterprise selector. Banking Forces is a short sequence of distinct drivers: rates/customer choice, the reporting timetable, critical providers, and Lloyds' company-described AI controls. Material timing, entity and uncertainty qualifications remain beside the intelligence.

Selecting Nationwide in an authorised Banking workspace immediately presents consolidated Group FY2026 income, underlying and statutory profit, the profit reconciliation, member rewards and integration context. It requires no `analysis` query, source expander or Financial destination hunt. Guest sees eligible public **Nationwide Building Society** complaint information instead, with a visible header **Sign in**. The two reporting subjects are deliberately different. This change grants no anonymous right to private earnings runs.

All seven streams retain their exact imagery and contextual navigation. Ordinary Main emits no research/source `<details>` and no source-document anchors, including hidden markup and print. There is one unobtrusive licence link only where the rendered information requires public-sector attribution. Owner Research inspection retains the original full composition and source/definition/calculation detail under its verified authority.

## Root cause and limits of diagnosis

1. Guest is the real anonymous decision from `verified_context`, not a cosmetic label. `package.upload`, verified membership, workspace selection and `BK-IND-002` resource ACL govern the existing Financial refresh POST. Hiding that action from Guest was correct. Forged role headers never establish authority.
2. The old Nationwide selection defaulted to a public FCA service profile. The persisted private Financial run was separately linked by `analyst.navigation`; selecting the company did not compose that analysis. An absent own-workspace run also meant no Financial entry.
3. Shared statement/agenda/proof rendering serialized source links, methodology, citations and multiple disclosure trees into normal Main. Merely closing those controls would retain the unwanted reading and print complexity.
4. The application now uses the existing eligibility checks with a request-local editorial composition. Research rendering and retained records are unchanged. The protected `lens=inspection` path remains Owner-only; private analysis still requires its own fresh Financial and resource checks.
5. Real Chromium printing was reproduced before and after. Native details were closed before and after printing in this environment. We did **not** establish that the owner's browser opened them for print, and do not claim it did. Before/after PDFs measure output directly.
6. The owner's three production PDFs are described by the commission but were not available in this checkout. Public Render deployment inspection was unavailable. The screenshots here are real loopback application renders against the merged baseline and candidate, with isolated genuine session/ACL services. They do not prove the currently deployed SHA, account membership, proxy/cookie configuration or browser settings on Render.

## Owner walkthrough

- Guest: `/industries/banking`, then select **Nationwide Building Society**. FCA data is Society-only and has its own October 2025–March 2026 window. No private title, run ID, earnings, workspace or prepare action appears.
- Sign in through the real header account entry and choose an authorised workspace. No membership or resource grant is created by this sprint.
- With existing `package.inspect` and Banking ACL, select Nationwide. A current own-workspace Financial run appears immediately.
- If the run is absent, only an actual Owner with `package.upload`, Banking ACL, eligible current source and CSRF session sees **Prepare financial view**. This calls the existing origin/CSRF-protected POST and returns to Nationwide. A GET never creates a run. Inspect-only users cannot prepare it.
- Authorised Owners use the compact FLORA menu's **Financial research** / **Research inspection** for sources and reasoning. Ordinary users do not receive that menu destination. Existing Research/Financial pages retain provenance.
- Change Landscape/Forces, use Back/Forward, use the bank selector, and follow UK → Banking → Lloyds. Selection and context remain in the existing URLs.
