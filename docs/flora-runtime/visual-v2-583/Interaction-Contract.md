# Two-screen interaction, artwork and ownership contract

## Fixed surface and geometry

Exactly two HTML endpoints, on a finite public-route allowlist. Only GB is supported; absent market defaults to the explicit UK design configuration. FR/global/blank/duplicate/private selectors fail closed. No IP/GPS/device inference, employer territory inference, location permission, market cookie or profile write. Header presents UK economy and PESTLE beside FLORA, with one compact Menu and one optional Sources & method disclosure. This UK-only proof does not offer a nonfunctional multi-country picker.

UK artwork: one 1536×1024 source, with stable `uk-sic07-a` through `uk-sic07-t` IDs, image-relative coordinates and an independent `RESEARCH` coverage registry. Desktop/iPad render its two adjacent exact halves as a seamless whole. At ≤600px the same halves stack, preserving every district and aspect ratio; each point is transformed from full x to half-local x without regenerating an image. DOM/read order follows the folds. Artwork can change independently of route/research logic, provided a versioned mapping is reviewed.

PESTLE artwork: 1536×1024 desktop and 1024×1536 portrait companion. Native labels use documented percentage anchors, with alternate mobile coordinates and intentional cover framing within a 720px minimum portrait canvas. On 320px the outer edges crop; the six labelled motifs remain identifiable. Labels have 44px+ targets and do not overlap each other or the selected insight. All six remain reachable while one insight is open. Replacing an asset requires new geometry checks, not new research/matching code.

Only the three supported sub-sector anchors are interactive in Home. Inert district labels are actual text, not disabled fake controls or invisible links. Later coverage can enable an existing zone by adding a supported route to the coverage registry, reviewing scope/rights, and rerunning navigation/accessibility checks. It cannot grant access to protected destinations.

## Native interaction and accessibility

No-JS anchors implement both screen navigation and six factor states. `factor` selects one state of PESTLE; `#insight` reaches a focusable, labelled over-image aside. The close anchor returns to the selected factor. All controls have visible keyboard focus; a skip link reaches the focusable main. Figure captions/text supply conceptual-map and measure semantics to screen readers. There are no hover-only, canvas-only or click-only targets.

Header Menu/Sources are native exclusive disclosures. The nested statistical table remains inside Sources. Minimal JS adds Escape close/focus return and selected-insight focus; it does not fetch, match, store, score or mutate anything. Source inspection is available once from the header, not repeated beside each claim. Source popovers remain within viewport and scroll independently; they are disclosures, not modal dialogs, so keyboard focus is not trapped. Existing sign-in/workspace routes and CSRF-decorated POST sign-out remain owned by the authentication layer. Storage/operational safety warnings in the HTTP handler still precede prototype rendering; they are not hidden to satisfy design purity.

## Financial presentation slots for later levels

| Level | Slot / example in this proof | Mandatory meaning | Omission/estimate rule |
|---|---|---|---|
| Country | £2.62tn GVA | UK, 2024, GBP, current basic prices; rounded official £2,623bn | No GDP/revenue substitution |
| Industry | Host-section share, e.g. Finance & insurance 8.1% | UK section K, 2024, same GVA denominator; Banking is a subset | No fabricated Banking/Technology/Aviation subtotal |
| Growth | Economic selection +0.7% real GDP | UK, three months to September 2026 versus prior three months, volume/seasonal basis | No mixing with current-price GVA or extrapolation to accounts |
| Employment | Reserved; not displayed here | Geography, year/period, headcount/jobs/FTE definition and source | Omit until supported |
| Enterprise | Contract only; existing NVIDIA/other enterprise views untouched | Revenue/profit/workforce, currency, fiscal period, global vs UK footprint, source owner | Global revenue must not become UK market share |
| Estimate | Contract only; none used here | Visible **EST**, range, explicit method, inputs, geography and period in optional detail | A guessed figure or copied global metric is omitted |

These are presentation fields over existing source/claim/financial owners, **not a parallel Evidence architecture or new intelligence schema**. A source ID/locator and original status remain attached beneath the view. Rendering cannot accept/promote a claim, bind an enterprise identity, settle source rights or turn an interpretation into a fact.

## Preserved owners and boundaries

The prototype reads public frozen statistical metadata and existing validated macro sources. It never calls Offers snapshot/discovery/mutation, private mission/employer profile resolution, Pipeline, enterprise registry, external network, research factories, agents or paid runtime models. Private seller/company information is deliberately not rendered. Only verified authentication context is used for the existing workspace/sign-out controls; forwarded user/role/country headers confer no authority. Revoked sessions lose those controls. Existing no-store, same-origin/CSRF and storage-recovery handling remain.

The protected-owner manifest fingerprints canonical Home's function plus research, permission/security, navigation, Offers, employer/mission, Pipeline and release owners against #580. Existing source/domain files are unchanged. Only finite route/asset wiring, the public allowlist and additive CI coverage touch existing code. #582 and #580 branches remain unchanged. No new canonical records, seller offers, assessment IDs, approvals, relationships, persisted market selection or Pipeline opportunities are created. Public static artwork/model labels are not researched relationships or inferred enterprise impact.

Internationalisation remains future work: country-specific source/taxonomy reconciliation, local researched-route eligibility, language/long-label/RTL geometry, currency/period formatting and jurisdiction checks need explicit contracts and visual approval. Do not relabel this UK scene or carry its weights/forces into another country.
