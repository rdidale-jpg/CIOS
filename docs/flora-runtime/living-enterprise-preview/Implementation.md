## Self-critique and remaining limits

The preview provides the smallest ordinary-browser evaluation path without replacing the accepted current experience. A visible experimental notice adds one modest line above Main; the main interface retains one illustration, one key message and progressive detail. The same original interior across layers provides continuity but remains conceptual. Its geometry cannot establish real organisational structure or economic weighting. Portrait necessarily trades persistent art for Main-first reading; selection collapses the scene even when only the hash changes.

An already displayed page or independently saved/printed document cannot be retroactively erased. The runtime serves no snapshot/export, keeps no preview intelligence cache, sends `no-store`, rechecks Source on requests and reloads restored browser documents; browser tests verify withdrawal through history/reload/print and removal of the accessible change marker. This is lifecycle enforcement, not a claim of push updates to already open pages.

These are simulated Chromium tablets/touch, not physical iPad/Safari or screen-reader certification. Live page browsing is unavailable under the environment network policy. Current service/deployment identity is verified through read-only Render metadata. Final owner visual acceptance and separate merge/deployment authority remain outstanding. No independent reviewer was commissioned by this bounded task; this is an architectural/UX self-critique.
