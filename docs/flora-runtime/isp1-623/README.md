# FLORA ISP-1 — intelligence semantics and clean presentation

Implementation for [Issue623](https://github.com/rdidale-jpg/CIOS/issues/623), based on validated main `fe66516c15726dc45de147ede2674c9172f8cac6`. **Draft for owner review; no merge, research acceptance, production change or deployment.**

The UK/Banking/Lloyds seven-stream journey now presents declarative intelligence with a small shared read-only policy. Reported, Calculated, Estimated, Working assumption, FLORA Insight and Hypothesis are separate presentation types. Verification and canonical acceptance remain independent. Ordinary reported statements have an accessible type without a badge on every sentence. Targets and proposed policy retain explicit labels, reporting periods, scope and proportionate caveats. Sources, method, reasoning and counter-evidence remain optional native disclosures.

Research gaps, questions, recommendations and evidence-administration records no longer appear in these core pages, including their hidden HTML/attributes. Unsupported details are omitted instead of displaying an empty analytical slot. Existing underlying research remains byte-identical. Legacy Banking research inspections/exports, Lloyds research diagnostics and specialist lens pages now require the **existing verified owner role**; anonymous users and sellers cannot retrieve them. Owner inspection still uses the original source excerpts and records. PR603's separate Command Centre design is not implemented or modified.

All seven accepted original artwork hashes and all21 delivered responsive variants are unchanged. UK→Banking→Lloyds, stream/selection context, native deep links, Back/Forward and no-JavaScript navigation remain supported. The existing six-factor UK PESTLE also consumes the same semantic presentation, without its old commercial-question footer or raw lineage JSON.
