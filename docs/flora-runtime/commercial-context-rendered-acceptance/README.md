# Commercial Context rendered acceptance evidence

These deterministic HTML captures are generated from the runtime render functions with explicit human-supplied pilot fixtures. They contain no hard-coded production profile and do not modify an imported Twin.

1. `01-commercial-settings.html` is the before capture of the schema-like Commercial Mission and Employer Context form, including its repeated statuses and save controls.
2. `02-recomposed-twin-map-and-rationale.html` demonstrates configured status, recomposed opportunity ordering, and an inspectable “Why relevant?” rationale without modifying evidence, confidence, timing, or governance.
3. `03-advanced-inspection.html` demonstrates the corrected Advanced Inspection identity, technical collection retention, and “Back to Twin Map” route.
4. `04-guided-commercial-context.html` is the after capture. It demonstrates the guided About Me, help-me-find, and commercial-context sections; the single derived status; the collapsed employer settings; the explanation of relevance boundaries; and the single save-and-return journey.

The after capture uses the runtime responsive stylesheet and is also the narrow-screen acceptance artefact: at 600px and below the status and actions stack in source order and controls retain the available viewport width rather than creating a second mobile experience. The exported Research Gap brief is text/Markdown by contract and is covered programmatically because browser styling is not involved.
