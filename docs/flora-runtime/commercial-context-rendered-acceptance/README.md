1. `01-commercial-settings.html` demonstrates the working Commercial Mission and independent Employer Context fields, field status labels, independent save controls, validation-capable POST form, and return to Twin Map.
2. `02-recomposed-twin-map-and-rationale.html` demonstrates configured status, recomposed opportunity ordering, and an inspectable “Why relevant?” rationale without modifying evidence, confidence, timing, or governance.
3. `03-advanced-inspection.html` demonstrates the corrected Advanced Inspection identity, technical collection retention, and “Back to Twin Map” route.

The settings page uses the runtime responsive stylesheet and is the narrow-screen acceptance artefact: fields collapse to the available viewport rather than creating a second mobile experience. The exported Research Gap brief is text/Markdown by contract and is covered programmatically because browser styling is not involved.
