**Method.** Identify reporting/legal perimeter before copying a measure. Use the original issuer/regulator endpoint and a page/table locator. Distil minimal factual propositions, preserve units/basis/precision and actual/target dates. Compare only matched periods and definitions. Use bank economics for credit/funding, mutual member value for societies, service-system economics for operators, capacity/platform/IP economics for providers and public mandates for regulators. PESTLE gives context; Five Forces compares value-system roles; value chains and conceptual capabilities explain mechanisms; relational SWOT is expressed as sourced strengths/responses, conditions/dependencies and counter-cases rather than ungrounded scorecards. No new framework database.

All new value chains and durable capability decompositions are analytical reference structures. They are not organisation charts, actual reporting lines, measured capabilities or verified customer value streams. An implementation requires a named stakeholder, initiating need, fulfilment/control hand-offs, delivered result and actual responsible owner. Existing platform/role facts can anchor a partial slice without pretending a complete internal model.

Each Insight identifies its input claims and discriminator. Conditions and existing remedies are not customer-confirmed pain. Commercial questions belong to this owner pack, not core FLORA. A provider collaboration is a brand-scoped directed edge unless exact legal parties are sourced; national CTP designation is a different predicate. Source withdrawal removes documentary dependants in QA; actual production revocation/ACL remains the existing runtime owner's job.

**Portfolio reconciliation.** Actor occurrences are not additive to route refs/narratives/financial dossiers. `BK-ENT-003` collision remains owner-qualified; no bare-ID merge. Supporting identities remain individually assessed but not falsely enriched to deep-Twin completeness. Source/canonical/public and research-readiness dimensions remain separate.
