# INT-MAP-1 — What's changing in the industry?

**Decision draft, 17 November 2026. Design and assessment only.** Commission
[#653](https://github.com/rdidale-jpg/CIOS/issues/653). Verified current main:
`fbac4c37910ed07b2baa516e1a5c8d7f329086de`, AUTH-2 merge; full post-merge
[main CI passed](https://github.com/rdidale-jpg/CIOS/actions/runs/44174841384).
This is a code/repository stocktake, not inspection of live Render or private
canonical records. Existing draft #657 and its initial assessment head
`3ebdcafa5bd36f00e1a5980a34797e6af3a60457` are preserved and strengthened here.

**FLORA has many useful intelligence components, but no demonstrated continuous
UK → Industry → Enterprise → Industry learning loop.** The accepted illustrated
experience reads a bounded, source-sensitive selection of research. Canonical
memory, external-change interpretation, package dependency review, financial
recalculation and private seller staleness already exist. They are not all wired
into those scenes, and navigation between them is not data propagation.

The next investment should connect those owners and improve editorial synthesis,
not create another engine, graph database, approvals queue or autonomous service.

## Product decision

| View | Question it should answer |
| --- | --- |
| Landscape | Who participates, how the industry works and where value is created |
| Forces | Why it behaves and evolves: economics, regulation, competition and operating mechanisms |
| What's changing? | What materially changed during a stated period, where it reaches and what the evidence supports |

**Provisionally favour a distinct Banking “What's changing?” stream**, after owner
comparison with a smaller change pulse in the existing view. It must earn the
extra place through dated, differentiated intelligence, not repeat today's four
Forces stories or become an article feed. Keep Top / Left / Main and one consistent
subject selection. Current selected-bank state survives a lens switch even when
the Forces composer shows industry content; that mismatch needs correction in a
later implementation, not another independent bank selector.

[Design-only interactive concept](concept/index.html) and [responsive previews](Previews.md)
illustrate the decision. The three required examples are **older context**, with
May–July 2026 publication dates, not current-week or current-90-day News. The concept
names its historical period and cannot justify activating a fresh News service.

## What is connected today?

- **Working intelligence → editorial views:** existing source eligibility, exact
  financial inputs, six semantic types, pinned agenda dependencies and public
  projections. No universal canonical Evidence acceptance is needed for permitted
  analytical views; private Financial runs remain separate.
- **Accepted ingestion → durable memory:** canonical Evidence/Observation/Enterprise
  Model services, authorised import/review/promotion and lifecycle reconciliation.
- **Governed external change → assessed enterprise applicability:** an existing
  read-only interpreter uses canonical support and relationships. It is not a
  general news/ripple engine and is not connected to the seven public scenes.
- **Promoted package change → pending dependent review:** exact subject-reference
  discovery records reconciliation work; it does not mutate dependent Twins.
- **Private research/Offer changes → seller staleness:** existing dependency digests
  require explicit reassessment and reviewed Pipeline hand-off.

**Not demonstrated:** regular News freshness, general cross-scope recomposition,
comparable peer-to-industry synthesis, enterprise-to-UK learning, verified provider
workload exposure for every bank or automatic Twin maintenance. Repository code and
candidate packs do not prove populated production records or enabled collectors.
