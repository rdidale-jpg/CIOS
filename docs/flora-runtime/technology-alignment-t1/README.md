## Architectural critique

The alignment is a presentation adapter over the established Technology renderers. It uses the existing reading control style, with finite native links scoped to the five presentation endpoints. The mode preserves accepted URL selectors. Current context shows the district and participant independently. The eleven supplementary records include role and commercial context. On this main cut, one participant has a populated UK numerical cell. A provider name does not bind legal or canonical identity.

Commissioned Technology art stays the arrival anchor. The comparison uses it as context, while enterprise profiles keep their editorial focus and a route back to the district. The existing broad comparison table still needs its own horizontal scrolling on narrow displays. A redesigned mobile comparator is a separate decision.

The current Facts composition retains history and labelled research disclosures for legacy deep links. This means some historical commercial context is still inspectable from Facts. The dedicated Insight route displays the selected retained interpretation or an explicit unavailable state. There is no simulated Forces or live change tab. A complete framework view for each Technology subject would require eligible material at the appropriate scope.

Both modes rely on existing hash-pinned research and comparison reads. Mutation of a pinned package fails closed. These static fixtures do not provide granular current publisher withdrawal for an individual retained claim. Equinix legacy figures still have their existing fixed presentation scope and publication date. T1 adds no derived financial figures or rights, identity or scope extensions. Contract actuality, exact deployment geography, UK entity attribution, and original-source reuse rights remain unresolved where the existing records say so.
