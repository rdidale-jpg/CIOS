# Bounded roadmap, migration, validation and owner decisions

## Immediately simpler interpretation — no runtime change here

- Stop treating canonical promotion as a universal prerequisite for accurately attributed analytical views. Accepted ADR011 and existing permitted views already distinguish them.
- Do not require canonical Observations for every chart point, calculation, scenario or analytical sentence.
- Do not present routine source-use review as a separate new legal decision for every cell when an applicable approved decision can be referenced.
- Do not confuse acquisition validation, candidate checks, legal use, canonical acceptance and projection completion. Neither a source URL nor AI confidence grants another state.

These are architectural conclusions/recommendations. They do not admit the five issuer sources, modify current controls or authorise an implementation. Source/legal defaults and actual runtime changes need the approvals below.

## Migration/compatibility strategy

Preserve existing Source/Evidence/Observation/Enterprise Model identifiers, accepted state, source/receipt lineage, schema readers and original research. Add versioned temporal/typed payload semantics for new values, with explicit old→new mapping previews and read-only comparisons. Keep old FY/prose values historical until safely rebuilt from accepted lineage; do not silently reinterpret their periods or overwrite source facts.

Existing Financial run/candidate storage remains working data under the same owner. No new financial database, source registry, qualification engine or copied research truth store. Separate future policy/adapter migration from source admission and canonical promotion. Any existing auto-acceptance route remains under actual verified write authority; do not route analytical reads through it.

## Future implementation test/rollback matrix

- Correct stock/duration/ratio identity, fiscal calendars, signed units/currency, source precision/rounding and legal/segment/perimeter; deny wrong-row/sign/basis/target/actual/Group joins.
- Calculations reproduce from input revisions; estimated/assumed dependencies remain visible; scenario outputs never become reported/accepted facts by arithmetic. No automatic annualisation/FX/like-for-like adjustments.
- Typed candidate and chosen accepted payloads round-trip through actual repositories; Model numeric value and source/Observation lineage survive restart. Dynamic attributes/prose fallback do not count as success.
- Genuine source permissions: exact use/audience/retention/attribution, third-party/expression exclusions and current origin/redirect safety; no source permission from category name or a public URL.
- Source withdrawal/revocation, stale/expired support, contradictions/supersession and private/tenant scope remove dependent facts/derivations/titles/counts/cache/export at use. Preserve lawful original history and distinct editorial/legal expiry semantics.
- Item/subset canonical review, real identity, duplicate/conflict decisions, source/target/review/plan fingerprints, recent authority, idempotency and safe existing compensation. Analysis alone creates no approval, Evidence, Observation, Material Pressure, Opportunity or Pipeline entry.
- Preserve seven illustrations/variants/portraits, scope/navigation, six semantics, accessibility, Offers/employer/private seller and Pipeline boundaries. Full local/hosted security and existing failure/skip comparators remain unchanged.

Rollback is separately reviewed and bounded per sprint. Candidate-view rollback removes the adapter/feature and invalidates its output; canonical rollback uses existing history-preserving compensation only if separately authorised. FIG-1 itself has no runtime/data migration: revert its offline documents/tool/tests/workflow and rerun checks.

## Success criteria, without fabricated benchmarks

Compare a measured baseline against candidate operation on the same eligible cases: material A–J dimensions actually source-backed and usable; analyst ability to explain five different economics/bridges; preserved values after reload; rejected invalid comparisons; complete source-to-output lineage and revocation; routine interventions per source/report/exception rather than per chart point. Measure elapsed time and review counts before setting targets. No unsupported savings, quality score or complete-research percentage is asserted here.
