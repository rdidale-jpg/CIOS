# Reproducible non-production proof

Run `python tools/research/fig1_demo.py`; compare with [Demo-Output.json](Demo-Output.json). This is a **fixed synthetic example**, not a new financial engine, source registry, application route or implemented OptionB. No actual bank data enter the demonstration. Example source/subject/evidence strings are deliberately fictional and confer no rights or real canonical authority.

| Required case | Actual exercised behaviour | What it does not prove |

| Reported flow | Fictional12GBPbn income for1Jan–30Sep2026 | Annualised bank revenue or a source-reported actual |

| Revoked source | Existing `restricted_metadata` denial precedes example rendering | A complete generic source-use evaluator: absence of a deny flag is not permission |

The proof also shows six existing semantic classes, source/method/caveat rendering and assumption dependency retention. Existing arithmetic calls an assumption-dependent result Calculated; the proposed future adapter must keep its weaker basis visible as Estimated or explicitly assumption-dependent, never Reported truth. The demonstration supplies the existing Estimated/Working assumption views without changing runtime semantics.

## How the existing implementation falls short

- `normalise_reporting_period('30 September 2026')` producesFY26 with2025-04-01→2026-03-31: unsuitable for a stock date.
- Deposit metric/table meaning remains unsupported, and `_financial_model_value` returns its deposit sentence rather than a numeric projection.
- A dynamic `normalised_amount` is not a persistent Observation field. Metadata persistence is possible, but the future payload must be validated/consumed by its existing Financial/memory owners.
- `mapping.evidence_is_current` treats accepted+stale or boolean withdrawn/retracted/core_contradiction examples as current. These are recorded limitations, not desired acceptance policy. Current presentation handles explicit deny encodings separately; neither helper alone is permission.

Every demonstration result states zero canonical writes/acceptances, new source permissions, owner-repository reads and paid calls. Only temporary, generic example numeric JSON is written and removed. Observation-shaped examples are transient `candidate` format probes with fictional Evidence strings; they are not real accepted records, persisted Observations or receipts. No actual approval, transaction or source receipt is constructed.

[fig1_quality.py](../../../tools/research/fig1_quality.py) separately checks the five authentic research exemplars/50dimension assessments/17actual gate references, signed reconciliations and current issuer-policy denials. Those checks prove artifact consistency and arithmetic, not complete financial research, current legal permission or a working live analyst product.
