## Recommendation and challenge conditions

**Choose B, start with A's measurement/candidate correctness work, defer C.** This is grounded in accepted ADR011 and actual candidate-only rapid results, candidate agenda releases and noncanonical Statement calculations already on main. Canonical Observation/Model migration must not become a prerequisite for the first actual analytical result. It is an extension of working ownership, not a fresh intelligence engine.

B fails if it merely renames blocked research as analysis, leaves every bank with a new bespoke renderer/review pack, uses a second financial store, treats calculated assumptions as reported fact, or drops source/tenant checks. It also fails if its delivery waits on a complete industry research catalogue before one bounded view becomes useful. The roadmap has independently useful stages and source-use blockers remain visible to owners.

A remains sensible if the owner only wants a narrow durable financial pilot. It is insufficient for the stated breadth if chosen as the final architecture. C should be reconsidered only after measuring B's remaining duplicated work and proving that changing financial Observation ownership yields real benefit without weakening source-to-memory lineage.
