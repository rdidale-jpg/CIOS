# Later sales-engine sprint — recommendation only

After owner acceptance of this visual system and the separate #578 release checks, consider a bounded **Offer-to-Sales v2** sprint. Start with one owner-selected employer-approved offer and one explicitly identified, authorised buyer account. Reuse the existing matching engine, assessment identity, source cutoff and versioned proof; do not create a second scorer or infer the buyer from an enterprise profile headline.

Prototype a human-reviewed next-conversation brief, then an explicit, permission-checked handoff to the existing manual qualification flow. Keep proposal/approval state, buyer role versus buying organisation, evidence gaps, TCV basis, stage versus customer validation, optimistic version checks and provenance visible where a decision depends on them. Test other-seller/private variation isolation and account-scope denial before widening the pilot.

Acceptance should require a user confirmation before any Pipeline create/update, preserving its existing writer and audit. No autonomous outreach, background agent, paid research/model activation, customer-demand claim or speculative supplier relationship is included. This document is a scoped recommendation, **not implementation or approval to begin that sprint**.
