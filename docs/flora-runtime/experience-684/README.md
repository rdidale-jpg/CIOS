Two enterprise archetypes use the same presentation functions for distinct root economics, the Inside value stream and durable capabilities, and the Forces condition/response/consequence composition. Banking Forces relates five structural forces to existing Landscape stages and contextual PESTLE. Facts is the default. Native mode links retain subject and perspective; evidence retains the owner’s dates, units and scope.

## Browser review and rollback

[Actual application previews](previews/) cover eight scenes in both modes across desktop, iPad landscape/portrait and mobile 390/320. Run `python -m tools.research.experience_684_browser /tmp/flora-684-previews` against an isolated development workspace with Chromium and Playwright installed. Earlier layouts at the same runtime baseline are in the [observed design archive](../../product/flora-experience/experience-align-all/previews/observed/).

The review checks native navigation, accessible landmarks and headings, visible focus, touch, history/reload, 320px without JavaScript, 200% CSS zoom, viewport fit and existing specialist examples. Chromium device sizes are simulations. Safari and physical iPad validation remain for owner review. Browser loopback timings are smoke observations and do not establish production latency.

The self-review found the Inside example useful for distinguishing activity from ability, with scope labels and missing real roles/operating measures still material. The force compositions show the break between national context and enterprise exposure, with banking competitor comparisons still conceptual. Independent architecture, evidence/commercial and executive visual critiques were unavailable for this PR.

Rollback is a revert of this bounded integration commit. No schema, permissions, data migrations or production state changes are involved. The historical exact-hash compatibility chain recognises the two reviewed presentation-file revisions; the comparator, security owners and historical checks retain their existing rules.
