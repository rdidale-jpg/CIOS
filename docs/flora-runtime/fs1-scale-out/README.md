# FS1 · Public Factual Intelligence Scale-out

**Decision requested.** Approve a bounded second-issuer implementation for review, conditional on verified Source inputs and ordinary-use conditions. Keep the shipping Lloyds exception inactive. This assessment changes documentation only.

## A. Executive conclusion

The ordinary factual-use category already works at the **Source eligibility** layer. It can evaluate compatible records from different already-recognised official publishers without asking for a licence per issuer, an approval per number, a canonical promotion or a private run. It does **not** yet provide a reusable **public Source-to-view path**. The positive policy test swaps the publisher URL on a test double and calls the eligibility predicate alone. Neither that test nor a public filing establishes primary verification, a valid issuer binding or a shipping financial slice.

Use easyJet as the first conditional proof. Its publisher origins and Landscape are already supported. Validate one report and one reported Group monetary fact through the existing Source owner, then show it via the existing aviation Economics composition in a future implementation. Add a second matched period and one existing calculation only if both inputs are eligible and semantically comparable. This is a proposal for architectural review, not release approval.

## E–H. Recommended increment and rejected alternatives

1. Keep a **finite, server-selected public subject/view** resolved by the existing Source snapshot owner. Reuse confined loading, ordinary eligibility, minimal fact identity, version and binding validation. Keep specialised existing source/legal guards where they apply. No publisher/input selection from arbitrary viewer URLs, no writes and no generic scraper.
2. Add one transient **public read projection** for one eligible easyJet Group report and one verified currency metric. Validate identity/perimeter/period/basis/unit/precision against Source-owned bindings and pass through typed objects with exact revision/locator. Keep issuer-specific definitions as validated data. Public attribution remains bounded and never exports internal or private locators. Avoid coupling new facts to the F1/F2 selector catalogue.
3. Use the existing Aviation Economics stage and ISP-1 rendering to show the reported fact and genuinely supported original interpretation. Reuse a compatible existing Financial function for a matched-period comparison only after validating both Source inputs. Keep source dependencies explicit and re-resolve them on every controlled read. No chart extension in the first increment.
4. Prove second issuer via isolated fixtures first. If no eligible easyJet document is established, keep its shipping projection inactive. After review, prove a second period with unchanged operations without another discretionary rights marker. This PR requests no live activation.

**Remove accidental constraints.** A renewed licence, per-number review, canonical promotion, private run, Python renderer per issuer, or second rights registry is unnecessary. Keep document/fact verification, authoritative issuer binding, signed-off exceptional scope where applicable, operation-specific attribution and live withdrawal.

**Rejected alternatives.** Expanding the private Financial selector would expand authority unnecessarily. Promoting to canonical Evidence would conflate public display with enterprise memory. Copying the Lloyds case into per-issuer branches would duplicate code and hide which safeguards are generic. A destination-wide allowlist or automatic scraper does not prove issuer identity, access rights or proportional acquisition. A new rights/financial service duplicates owners. Upgrading Equinix or BT by converting existing presentation evidence into released facts would overstate eligibility. ## J. Self-critique and unresolved decisions

This is a repository and isolated fixture assessment. It does not independently reacquire original issuer reports, adjudicate new terms, inspect production stores or certify eligibility. Thin first-release coverage limits the value of cross-industry comparison, but makes faults in the reused path attributable before adding more equations or issuers. Equinix and BT need origin, scope and Source-owner readiness work. Public selector placement, the minimal fact binding shape for stocks/percentages and lifespan of fixed legacy renderers are review decisions. Granular withdrawal of current Technology hardcoded facts is a separate lifecycle gap. ADR-027 stays Proposed and no legal case is resolved here.
