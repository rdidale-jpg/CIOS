**Source use:** existing public factual research presentation is retained for a bounded factual purpose. The adapter adds no publisher permission, blanket licence, report redistribution or canonical acceptance. Existing aviation records lack explicit rights objects; this is disclosed, not converted into a new rights grant or a claim that public accessibility is a licence. No protected original report text is reproduced wholesale. Original expression remains internal with existing research ownership; Main contains short, attributed factual projections. All later explicit restrictions, withdrawal, revocation, staleness and owner-only flags remove dependent output.

The snapshots are reviewed short excerpts acquired in earlier research, **not fabricated downloaded original-byte archives**. Source `primary_content_sha256` remains null where no original-byte archive exists. The annual report publication date remains unestablished; the UI dates the accounting snapshot, not an invented publication day. Retrieved-at dates never become event dates. Pins fail closed on changes to issuer, URL, period, definition or underlying claim.

## Intentionally omitted

- 163 airports / 37 countries and statutory PBT £658m: compound overlay statements extend beyond the exact retained annual-report cells. The useful supported route/fleet counts remain.
- ~30% cost share, ~350 current aircraft, ~14k staff, efficiency uplift or speculative AI gains from generated concepts.
- IATA global forecasts, UK airport journeys and H1/FY comparisons in capability metrics: incompatible perimeters/periods and no capability allocation.
- Search-index-only holiday/Q3 material, recommended acquisition claims, current executive accountability, exact planning systems, slot holdings, vendor workshare and contract values.
- Customer-confirmed demand, open procurement, external delivery gaps, budget, supplier eligibility or qualified opportunities.

## Remaining evidence requirements

Current fleet/network counts; dated current capability performance; supported accountabilities/process boundaries; verifiable planning-system dependencies; current supplier contracts and scope; route economics; realised technology outcomes. The available H1 FY2026 retained research could be assessed in a later separately reviewed extension but is not silently promoted or blended with FY2025 here. These remain internal research gaps, not empty Main fields or seller questions. Source rights/use-basis documentation can be deepened within existing owners; no change to source rules is made in this sprint.
