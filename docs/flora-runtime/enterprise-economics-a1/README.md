## Acceptance walkthrough

1. Open `/enterprises/lloyds?stream=landscape`. Select all three stages. Understand deposits, interest/fees and costs without opening evidence. Confirm Group, stock date and nine-month statutory-profit scope.
2. Select FLORA Insight, change stage, then use Back/Forward and reload the direct URL. The current stage and reading mode remain explicit.
3. Open Source & basis once. Confirm attribution, dates, accounting definitions, calculation method and material limitations. Lloyds links use its homepage; direct PDF links remain deferred.
4. Follow Financial analysis and the existing funding/customer-outcome perspectives. These retain their existing owners and entity boundaries. No qualified Material Pressure is invented to populate a link.
5. Open `/enterprises/easyjet/preview?stream=landscape`. Compare the warm airline treatment with the bank. Select all stages and switch modes. Follow Fleet Operations or Network Planning into the existing Inside experience.
6. Review desktop and both iPads, including the expanded portrait illustration; also check the 320/390px mobile and 200% zoom proofs. Source withdrawal proof removes numbers and dependent calculation/inspection/print text while retaining the conceptual stages.
