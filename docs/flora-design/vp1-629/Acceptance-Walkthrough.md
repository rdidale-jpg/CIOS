# Owner walkthrough and visual acceptance

This is a local, design-only prototype, not live FLORA. Download the design-assurance workflow’s prototype artifact (or this repository folder), keep `assets` beside the HTML files and open `index.html`. GitHub’s file viewer shows HTML source; no site is published. All navigation is native and works without JavaScript. The snapshot is15November2026, not a live research feed.

1. UK Landscape: inspect the constant country skyline and Main’s economic context. Select **Banking** in Left.
2. Banking Landscape: select **Lloyds** directly in Left. This completes the required two-selection journey.
3. Lloyds: switch **Inside / Landscape / Forces**, retaining enterprise and a selected topic. Select Technology & AI or Leadership Agenda; use Back/Forward and a copied file deep link.
4. Financial scale: toggle the2025 reference with mouse/touch/Space. The zero baseline stays fixed; the current deposit balance remains. Profit is a separate period measure, not placed on the deposits scale. Open chart data and Sources & basis.
5. iPad portrait/mobile: Left starts closed. Open it, select a subject, reopen and check context; collapsing retains focus. Main receives reading priority.
6. Open `concept-news.html` and `concept-tools.html` separately. They are labelled unavailable concepts; no current News edition, model execution or private action exists. Do not mistake these files for production streams.

## Owner acceptance checklist

- [ ] Three bounded regions feel coherent, premium and recognisably FLORA.
- [ ] UK skyline is recognisable and remains unobtrusive at every scope.
- [ ] All seven new portraits retain the accepted originals’ craftsmanship, depth, atmosphere and differentiation.
- [ ] Three prominent subject labels provide sufficient exploration; later full-hotspot mapping is accepted as a separate implementation gate.
- [ ] Main provides worthwhile intelligence capacity without repetitive copy, excessive cards or unnecessary panels.
- [ ] Financial bases, source dates, estimates/assumptions, targets, insights and hypotheses remain clear.
- [ ] Counter-evidence/source access is available without dominating the default view.
- [ ] Desktop, both iPad orientations and mobile feel balanced; physical-device and assistive-technology checks are accepted where needed.
- [ ] News/Tools are understood as separate future concepts, not delivered functionality.
- [ ] The original seven assets and 21 variants, IAM/Owner Command Centre, research owners, Offers and Pipeline remain unchanged.
- [ ] Explicit visual and architectural acceptance recorded before commissioning implementation.

No checkbox is preselected. This pack does not merge, deploy, approve Evidence or grant permission to change the application.
