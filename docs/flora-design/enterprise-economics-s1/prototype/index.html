What this study does—and does not—claim

Lloyds uses an explicitly illustrative banking mechanism. No restricted financial figures, PDF links, actual cost allocations or buying needs are shown. The §2 and §5 restrictions remain in force.

easyJet uses a few rechecked FY2025/2024 Group figures from its original annual report. Headline pretax profit is an alternative performance measure. These are historical results, not the latest trading picture or capability-level economics.

These files are a local, static design document. They do not modify FLORA, authenticate a user, create Financial runs, qualify pressures or create opportunities.
