## The proposed experience

One familiar, richly illustrated enterprise remains in Left. Four regions per layer select the explanation in Main. Landscape outlines the three reporting segments and Group economics; Inside reveals customer operations, credit/risk, applications and data/AI; Forces connects rates/funding, resilience, competition and renewal. A source-dependent Curve marker opens its relevant strategic-change context.

Main uses a single key message and explanatory value/operating diagram, with eligible facts and material scope. Group deposit **stocks** and nine-month profit **flow** are never allocated to a division. The architecture, rooms and flows are conceptual: this is not Lloyds' actual headquarters, a factual floor plan or a verified internal topology.

Overview → Explore → Investigate is retained as the contextual journey between Landscape → Inside → Forces. The existing top perspective control does the switching; there is no extra Main navigation row. All eight existing SWOT themes remain interactive in Forces. Inside omits financial statements; Landscape omits SWOT and the strategy timeline. Full source inspection stays with the existing authorised capability in actual Flora.

## What to inspect

1. Select Retail, Commercial, Insurance/Pensions/Investments and Funding in the illustration. Check whether the visual position helps rather than suggesting unsupported ownership or scale.
2. Use the top Inside control. The prior subject remains visible as context; content stays Group-level where a divisional relationship is unverified. Select customer operations, credit/risk, platforms and data/AI.
3. Open Forces. Inspect the funding transmission, reporting dates, competition and renewal. Use the Curve marker and eight SWOT themes. Distinguish management direction from delivered results.
4. Try Back/Forward, direct reload, keyboard and touch. On iPad portrait, open **Explore Lloyds**, select a region and return to Main.
5. Compare Banking's unchanged external ecosystem with Lloyds' internal architectural portrait. Review the same three perspectives on desktop and both iPad orientations.
