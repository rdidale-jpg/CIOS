# FLORA Experience Contract — owner decision and implementation handoff

**Status:** Proposed design acceptance record; no runtime implementation. [Full experience contract](FLORA-Experience-Contract-v1.0.md). Owner agreed the entire three-level concept and specifically prefers the **visible two-option** `Facts | FLORA Insight` control rather than an implicit on/off switch.

## Executive one-page experience matrix

| Scope | Primary Top controls in intended order | Initial Top view | Universal secondary control at top of Main | Main's Facts → Insight semantic shift |
| --- | --- | --- | --- | --- |
| **UK** | **Landscape · Forces · What's changing?** | Landscape | **Facts (selected) · FLORA Insight** | Real macro/economic, institutional and dated conditions → supported country/industry consequences and comparisons |
| **Industry** | **Landscape · Forces · What's changing?** | Landscape | **Facts (selected) · FLORA Insight** | Real industry structure, value system/economics, competition/participants and events → comparative mechanisms, pattern candidates and consequences |
| **Enterprise** | **Landscape · Inside · Forces · What's changing?** | Landscape | **Facts (selected) · FLORA Insight** | Real identity/economics, capability/process/technology/people, specific pressures and dated programmes → enterprise-specific mechanisms, strategic implications and falsifiable hypotheses |

**Availability:** The table is the **target IA**, not an assertion that all tabs presently work. Current main supports UK/Industry `Landscape|Forces` and Lloyds `Inside|Landscape|Forces`; a `What's changing?` view must be held pending meaningful eligible source supply, and Facts/Insight must be implemented as a new presentation capability.

## User journeys defining acceptance

**UK:** open Landscape Facts → select Banking → Banking Landscape Facts → select Payments → discover actual money/role mechanisms → select FLORA Insight → examine supported significance of the *same* payments subject.

**Industry-to-enterprise:** Banking Forces Facts → select dated critical-provider policy → Insight explains sector resilience relevance → navigate to Lloyds / Inside Facts → select an AI technology capability → Insight notes scoped brand collaboration, not an invented contract or proved operational harm.

**Financial trust:** Nationwide Landscape Facts shows Group FY2026 financial basis and mathematical reconciliation; Insight explains member-value and integration implications without replacing the reported basis or conflating Society complaint figures.

**Change:** UK or Banking What's changing? Facts displays dated changes in an explicitly bounded period; Insight explains supported impact and contradictory/unknown exposure; source revision/retraction removes exactly dependent interpretation. Sparse historical news does not activate a misleading “Latest” tab.

## Acceptance gates for a later code PR

- Two orthogonal choices: Top primary perspective changes Main's topic; in-Main reading mode swaps Facts and Insight **for exactly the same selected subject**.
- Facts always selected on first arrival, on new level/subject and ordinary shared links. Explicit Insight deep-link opt-in is permissible if all rights and state validation holds.
- Main Facts uses traceable, scoped and dated real information or **clearly labelled conceptual** value/capability models; no unapproved interpretation is smuggled in as a stated fact. An existing heading `FLORA INSIGHT` must not by itself classify a statement as factual.
- Main Insight uses existing semantic types, source permissions and lineage, never anonymous unvalidated reasoning or a guarantee of truth; no automatic opportunity, Model, Pressure or Pipeline promotion.
- Existing model and source authorities are retained: no new Facts/Insight truth registry, graph store, scheduler, product permission or publisher rights.
- Primary toggle labels remain level-specific: no UK Inside, no Industry Inside. News, historic change, upcoming, PESTLE, Five Forces, finance and ecosystem remain **contextual lenses/filters or selected subjects**, not competing top-level navigation.
- Top/Left/Main stays in FLORA's premium ivory/forest-green/gold style; UK geographic/economic scene, Industry value/ecosystem scene and Enterprise business capability scene are recognisably different. Visual differences cannot assert real-world links without source evidence.
- Selection/back-forward/reload/native link/no-JS/assistive labels, mobile/iPad layout, source withdrawals, rights, role/workspace/tenant boundaries and scope/time correctness all tested.
- Implementation PR compares actual screenshots before/after, source/insight classification, source removal, negative near-match, real browser UX and full current regression/security. Owner accepts artwork and scope separately.
- No merge/deploy of this docs contract is needed merely to read it. **Any future merge or live behaviour change requires explicit separate owner approval.**
