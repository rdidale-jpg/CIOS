## Root codes and evidential burden

Codes apply to the **named missing information/connection**, not an entire domain indiscriminately. Multiple causes may coexist.

| Code | Definition | Use in this audit |
| --- | --- | --- |
| A | Research not undertaken | No adequate result for the named deliverable found in the examined corpus; search boundary is explicit, not a claim of global absence |
| B | Research undertaken, relevant fact not extracted | A retained narrative/primary locator exists, but a reusable atomic/model input is absent or not decomposed for the intended question |
| C | Extracted but not correctly connected | Candidate/existing fact exists; legal entity, segment, capability, role, programme or supplier join remains unproven or unused |
| D | Legitimate source/publication control | A specific active Source/use hold or rights/operation condition applies. §2 applicability is unresolved, not adjudicated legal prohibition. A legacy `public_eligible:false` flag by itself is not a legal conclusion |
| E | Genuinely unavailable from examined accessible material | Internal contract, topology or outcome is not disclosed in the reviewed material. Broader public nonexistence is not proved; pair with H where further access/verification is needed |
| F | Eligible but not surfaced in the intended presentation | Identify an existing eligible item or synthesis and its missing target-screen mapping. It may already be accessible elsewhere. Large cards alone are a visual finding, not proof of a hidden fact. Does not mean richer candidates are currently publishable |
| G | Stale, contradictory or insufficiently verified | Citation-only evidence, changed roster/period, incomparable scopes or unresolved original support; a historical date alone is not automatically stale |
| H | Undetermined | Exact Source applicability, production state, canonical binding, private ownership or external evidence remains unavailable to this audit |

## Reproduce

From this branch's repository root, with the existing Python environment:

```sh
python docs/product/flora-experience/lloyds-intelligence-audit/census.py
python docs/product/flora-experience/lloyds-intelligence-audit/author.py
python docs/product/flora-experience/lloyds-intelligence-audit/browser.py
python docs/product/flora-experience/lloyds-intelligence-audit/validate.py
```

Browser requirements are the existing Playwright/Chromium dependencies. PDF inspection uses the existing PyMuPDF dependency. No paid provider, external model, issuer document acquisition or production mutation is called. `OPENAI_API_KEY` is removed in the isolated browser process; all runtime data is in a temporary directory. Captures have the actual capture checkout in their proof; baseline runtime hashes and the final doc-only validator establish unchanged application code. The scripts do not write existing research files.

Validation checks all required domains, root codes/references, finite-state counts, source/claim identities, typed reconciliation scopes, branch pins, screenshots/PDF hashes, Markdown links, and the exact changed-file boundary. The entire `cios`, existing `enterprise-knowledge`, tests, workflows, contracts and original artwork must match the baseline. A reversible documentation diff restores the exact baseline tree. No runtime security/failure/skip comparator is edited or rebaselined.

The baseline's full hosted security/regression run remains valid evidence for unchanged runtime. This documentation-only sprint does not falsely claim a new full runtime CI run merely because a draft PR is created. The final completion report records actual local audit QA, any triggered hosted checks and exact head SHA.

## Self-critique and remaining evidence

This is broader and more concrete than counting research documents: it traces finite screen inputs, examines held financial/role/customer material, distinguishes explicit source exceptions from poor verification, and reproduces layout problems without changing them. It still cannot prove a full enterprise model or globally exhaustive public search. The text census is a discovery mechanism, not manual reading of every line in 487 files. Research packages overlap and sometimes preserve reported verification whose original bytes are not retained here. Only bounded primary facts and existing source identities are reused.

Source/rights conclusions are proposed handoffs under existing authority, not legal advice or approvals. E/H assertions deliberately distinguish “not disclosed in examined material” from “cannot exist.” Owner live PDFs, production/authenticated rendering, physical Safari/iPad behaviour and canonical/private receipts remain outside the verified evidence. This audit is self-reviewed with deterministic checks and visual inspection; no independent agent or professional legal opinion is claimed.

Dropping this docs-only branch is a clean rollback. If ever integrated later, reverting its documentation commit removes the audit without a schema, data, permission or runtime rollback. No merge or deployment is authorised by this audit commission.
