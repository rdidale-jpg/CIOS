# Validation, scope and rollback

## Existing authority and bounded change

Baseline is `cc8d93fe7183fdd86fd4c4e81907a2a0764227a5`, with successful full main CI. The new implementation changes the existing Lloyds Main renderer and its stylesheet, the product presentation contract, focused tests and current-head visual assurance. It creates no parallel renderer, intelligence engine, data store, source-use registry or approval process.

`facts_for`, `reported`, `interpretation`, `scene`, `resolve`, `href`, `render` and `stylesheet` retain their original AST. The finite analysis-detail vocabulary adds four quadrant selections. All source/evidence research files, Source/Financial/IAM services, route/security ownership, original art and original Left markup remain unchanged. Existing legal and factual holds remain active.

## Meaningful interaction proof

`tests/test_flora_main_canvas.py` covers every finite Lloyds subject/detail state, including quadrant states. It rejects bare internal navigation, nested anchors and navigation labels inside data-table cells. Focused tests cover full business content, financial stages/bars, conceptual operating layers, capability/organisation/technology boundaries, dated rails, independent quadrants/themes, existing URLs, source withdrawal and immutable owners/Left.

`browser.py` uses real HTTP and Chromium at desktop 1440×1000, iPad landscape 1194×834, iPad portrait 834×1194 and mobile 390×844. Equivalent before/after routes cover Group, economics, organisation, operating model, capabilities, applications, transformation, goals and SWOT. The after run physically clicks the body away from the title for each composition, as well as quadrant background and themes. It tests touch, keyboard/focus, hover, selected state, no-JS, direct URL/reload/history, no overflow, 200% zoom and source-dependent print/accessibility output. Browser proof is emulation, not physical-device certification.

Source withdrawal is applied through the existing owning data input. Dependent chart bars, amounts, source-bound theme routes and accessible values disappear; independent eligible content remains. No export endpoint or static public snapshot is introduced.

## Reproduce

```sh
python -m pytest tests/test_flora_main_canvas.py tests/test_flora_lloyds_ceo.py tests/test_flora_lloyds_gold.py -q
python tools/ci/flora_ci.py --output /tmp/flora-canvas-ci
python docs/product/flora-experience/main-canvas/browser.py after /tmp/flora-canvas-browser
python docs/product/flora-experience/main-canvas/validate.py --browser /tmp/flora-canvas-browser
```

For baseline comparison run the same browser script by absolute path with `before` from a detached baseline worktree. Browser prerequisites are the existing Playwright/Chromium test dependencies. Committed screenshots record their actual capture checkout and runtime hashes; exact-head reruns are external/hosted artifacts to avoid a self-referential SHA claim.

## Rollback

No data migration, new Financial run, production or canonical write is introduced. `validate.py` proves that reversing the complete PR binary diff in an isolated Git index reproduces baseline tree `b876adc82e72347b7a563a4bdec0a96c9ff22725`. No checkout/shared branch or persistent store is reset during this proof. Any later approved revert is a normal reviewed code revert; existing historical preview/legacy routes remain available. No merge or Render deployment occurs in this sprint.

## Remaining limitations

The mandatory interaction rule is global; this runtime change is bounded to the current Lloyds executive renderer. Legacy/specialist and other-industry presentations are preserved and not falsely reported as fully compliant. Existing missing financial/workforce/current mandate evidence stays unavailable. Visual geometry and contextual links do not establish financial allocations, causal relationships, installed dependencies or buying intent. Owner visual/commercial acceptance remains pending.
