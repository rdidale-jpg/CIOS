**Baseline:** validated main `cc8d93fe7183fdd86fd4c4e81907a2a0764227a5`; [full main CI](https://github.com/rdidale-jpg/CIOS/actions/runs/45405585493). Implementation branch starts from main, not a design/research branch. ## Acceptance walkthrough

1. Open `/enterprises/lloyds`. Select the body of a business composition, away from its title. The complete region should open that business; the Left artwork persists.
2. Group economics: select a funding/lending/cost/capital region, then a date bar. Source dates, stock/flow and calculation caveats must remain intact. Held figures stay unavailable.
3. Inside: select a process composition, a capability, a reporting branch and a function layer. Every selected region should update Main through an addressable existing context; diagrams remain explicitly conceptual where not verified.
4. Transformation and strategy: select the body of a dated event or goal. A disclosure date is not delivery progress; a target is not an actual.
5. Analysis: click a quadrant background, then an individual theme region. Confirm separate destinations, clear selection, all eight themes where eligible, counter-evidence and no sales qualification.
6. Repeat with Tab/Enter and iPad touch, Back/Forward, direct reload and no JavaScript. Inspect sources through the separate inspection layer. Check mobile and 200% zoom; confirm no clipped or tiny interaction targets.
7. Verify the historical preview, prior default, Banking and Aviation/easyJet still work, with the same permissions. No industry-wide runtime rollout is claimed by this Lloyds change.

## Critique and limits

The gain is functional: selecting business context, a process or a complete chart now works across its surface. Distinct reporting branches, financial flows/bars, process layers and timelines avoid treating every subject as the same card. Navigation remains native and reversible.

The existing intelligence limitations remain. There are no new segment allocations, current leadership mandates, workforce counts, supplier contracts, budgets or progress metrics. Main's visual richness cannot establish missing evidence. The illustrations and conceptual lines are not measured financial shares, reporting relationships or installed system topology. Source rights and Lloyds §2/§5 holds remain unchanged.

Owner visual/commercial acceptance is still required. This is a self-critique supported by browser evidence, not a claim of independent design approval. Other industries and retained historical/specialist presentations require their own implementation audit under the global contract; they are not silently restyled in this sprint.
