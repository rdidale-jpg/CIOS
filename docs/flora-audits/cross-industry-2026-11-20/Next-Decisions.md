## Recommended smallest sprint: Aviation Journey Continuity (AJC-1)

**Problem:** the accepted-style easyJet operating-system experience exists, but the normal `/enterprises` catalogue and Aviation flow lead first to an older Enterprise composition. The current Industry page itself is also legacy, but rebuilding it would introduce a larger visual/content commission and a missing rich Industry-art dependency.

**Implement only:**

1. Make ordinary catalogue and existing Aviation “explore easyJet” navigation enter the current three-panel Enterprise experience in **Landscape / Facts**. Use existing finite context/navigation owners; preserve country/enterprise and exact selected capability where compatible.
2. Decide the narrow default-route treatment for `/enterprises/easyjet`: shared dispatch or explicit native redirect, while keeping existing specialist `lens` URLs, evidence/research destinations and legacy deep-link meaning addressable. No catch-all redirect of every query.
3. Keep the existing Inside capabilities (Fleet Operations, Network Planning, Customer Service), Forces, reading-mode transitions, native Back/Forward/reload, focus/close controls and portrait/mobile scene access.
4. Preserve richer legacy information through an intentional existing contextual destination where eligible; do not remove facts just because the default preview is shorter. No forced research click tree in ordinary Main.
5. If #701 has separately been integrated into the new verified baseline, reuse its Aviation Economics composition. Otherwise use current main's existing Landscape; **do not copy/rebuild #701 on an unreviewed branch**.

**Explicitly outside AJC-1:** Industry redesign/new art, airline/holidays financial admission, annual-comparison extension, new company/provider cohort, country expansion, News, source import, canonical promotion, new governance stores, automatic opportunities, private Financial-run lookup or persistence. No Source/legal decision inferred from visual approval.

**Acceptance:** a user can reach the already implemented three-panel easyJet experience through normal discovery without first navigating an obsolete default; specialist links and existing content remain addressable; all three capabilities and Facts/Insight preserve meaningful scope and history; current Source withdrawal and all permissions remain fail-closed. Desktop, both iPads, mobile, keyboard/touch/zoom/no-JS checks and full strict security/regression are required for that future code change. Produce a separate draft PR and stop for owner acceptance.

**Expected code ownership, not a prescriptive patch:** catalogue/enterprise entry dispatch and existing visual-stream link/context owners. Exact files/route behaviour should be chosen after inspecting the then-current main. No new Economics object, intelligence owner or source registry is needed.
