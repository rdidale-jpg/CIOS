## Canonical maturity is a separate question

The repository file `banking-research-canonical-objects.json` has 122 migration objects: 81 `lineage_verified`, 41 `owner_review_required`. It includes manifests, research documents, evidence/hypothesis registers, Unknowns and Contradictions. Neither its filename nor a verified archive lineage proves a current accepted Evidence → Observation → Enterprise Model projection. Likewise, TEL has a recorded **647 semantic candidate** inventory while its trace discusses **1,060 packaged/persisted wrapper records**: different layers/cuts, not two current accepted-model totals.

Actual production registry/receipts, current authorised source decisions, accepted Evidence/Observations, Model attributes and current qualified pressure assessments require the existing read-only authorised services. This audit does not enumerate or write those private stores and does not declare them empty. Existing import/Canvas/qualification services are therefore **implemented but population-conditional**, distinct from research availability and visual maturity.
