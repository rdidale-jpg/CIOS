# Industry-by-industry coverage

States are descriptive, **not maturity scores**. “Implemented” means a traced code path on audited main; “conditional” requires existing authorised records; “research” does not imply public use or canonical acceptance; “not found” is bounded to the tracked repository. Evidence IDs resolve in [Evidence-Map.md](Evidence-Map.md). Generic infrastructure can exist without a sector-specific screen.
