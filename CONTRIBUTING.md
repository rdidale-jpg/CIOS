# Contributing to CIOS

CIOS is being developed iteratively using ChatGPT, Codex and GitHub.

## Contribution Principles

Every contribution should:

- Align with the CIOS Constitution.
- Preserve explainability.
- Improve modularity.
- Include appropriate documentation.
- Avoid unnecessary complexity.
- Be traceable to a clear requirement, issue or architectural decision.

## Working Method

Follow the [Product Delivery Doctrine](docs/product/flora-delivery-acceleration/README.md) for ordinary development. Use **Build → Test → Merge → Review**. Read [CIOS AI Context](CIOS-AI.md) for the relevant architecture and specialist profiles.
